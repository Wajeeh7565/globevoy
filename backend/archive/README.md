# GlobeVoy archived backend evidence

This directory contains historical backend material retained for review, regression investigation, and reproducibility. **It is not a list of files to delete.**

| Folder | Historical contents |
| --- | --- |
| `validators/` | Older validation scripts and test fixtures |
| `validation-results/` | Recorded validation outputs |
| `release-reports/` | Previous backend change and quality reports |
| `release-evidence/` | Evidence files and release artifacts |
| `manifests/` | Build, change, rollback or checksum manifests |
| `scripts/` | Older build, audit, deployment or test helpers |

For active source-code entry points, see [backend README](../README.md).

**Preservation rule:** Some archived scripts are referenced by runbooks or allow older releases to be reproduced. Confirm both repository references and operational requirements before moving or removing them. Keep production and staging entry points untouched during archive housekeeping.
