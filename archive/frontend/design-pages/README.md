# Archived frontend design pages

These old mockups are not needed to run the website. The current editable classic pages are in `frontend/pages/`; React account pages are in `web/`. This archive is optional historical reference, not a second application.

These 31 files are older design/state screens removed from the active `frontend/pages/` tree during the November 2026 organization pass. Their original bytes are preserved and checked against `ops/frontend/page-layout.json`.

They include the superseded About/How/Trust designs, unused account/password forms and loading/error/result-state mockups. They are historical references, not current application pages. Relative assets still reflect their original location; do not treat the archive as a runnable or public website.

The production packager does not copy this directory. Old `/pages/...` URLs are represented by generated compatibility redirects; current source pages in `frontend/pages/` remain active. See `frontend/README.md` and the layout manifest before restoring anything. Do not edit historical files to make tests pass.
